# Marissa’s Voice Naloxone Finder

Free public directory of naloxone, treatment, and family-support resources operated by Marissa’s Voice Inc. (501(c)(3)).

**Live site:** https://marissas-voice-naloxone-finder.netlify.app/

## Purpose
Help people find free naloxone, treatment, and support near them. Every listing includes its source and last-checked date. Verification levels: Verified / Partly verified / Unconfirmed.

## Status
- National coverage for helplines and statewide programs
- Street-level ZIP search live in many metro areas (gold outlines on the map)
- Weekly state listing checks
- Last full state pass: October 16, 2026

## Repository Structure
- `/data/` — structured listings (JSON preferred) and schema
- `/docs/` — verification rules, update process, standing rules
- `/src/` — frontend source
- `.github/workflows/` — CI / validation

## Standing Rules
- Marissa’s Voice’s own naloxone distribution is listed only after inventory confirms kits on hand.
- Do not list a location as verified from a news report alone.
- Name the owning organization on every third-party helpline.
- Listings can change without notice; this is not medical advice or an endorsement.
