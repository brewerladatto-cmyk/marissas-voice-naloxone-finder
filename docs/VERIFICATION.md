# Verification Rules

## Levels
- **Verified**: We opened the operator’s page or an official government page on the check date, and the main facts on the card match it.
- **Partly verified**: The main fact checks out on an official page. Details listed as unconfirmed (hours, walk-in rules, stock, etc.) were not on that page.
- **Unconfirmed**: Comes from a news report or a source that gives few details. Call or check the source before traveling.

## Requirements for every listing
- Source URL(s)
- Date last checked
- Verification level
- Owning organization named for third-party helplines
- Coordinates preferred (real, from published sources)

## Standing Rules
1. Marissa’s Voice’s own distribution is not listed until the inventory ledger shows kits on hand.
2. Do not mark a location Verified from a news report alone.
3. Name the owning organization on every third-party helpline.

## Update Cadence
- State listings: weekly check
- City / metro listings: as needed, with date shown on each card
- Last full state pass recorded in site footer / about section
